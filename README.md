# Reference results

Outputs of the reference run of `notebooks/IKC_certified_FK.ipynb` used in the manuscript (Windows 10, Python 3.14, scikit-learn 1.9).

- `tables/` contains all result tables (CSV), T0 to T13; the table names match the section headings in the notebook.
- `figures/` contains all figures (PNG, 300 dpi).
- `run_log.txt` and `summary.json` hold the complete printed log and the configuration.

The two coverage-by-decile figures (F08, F09) were redrawn from `tables/T13_decile_coverage_width_S1_position.csv` with a y-axis that shows every point. The data are unchanged, and the current notebook already contains this axis setting.
